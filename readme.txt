== Description ==

This plugin is build with WordPress. It allows you to create business proposals, pricing, and signatures.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/asphalt-proposal-manager` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Configure the plugin in the settings.
